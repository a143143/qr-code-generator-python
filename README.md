# QR Code Generator using Python

This is a simple QR Code generator created using Python.

## Features
- Generates QR code from a given link
- Saves QR code as an image file
- Uses Python qrcode library

## Example
This QR code links to my LinkedIn profile.

## How to Run

1. Install required library:
pip install qrcode[pil]

2. Run the script:
python qr.py

## Output
A QR code image file (my_qr.svg) will be created.
